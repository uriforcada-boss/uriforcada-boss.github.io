Skills

Es la plantilla, no las skills: las tres partes que hacen que se dispare cuando toca y no cuando no, cuándo se activa, qué NO debe hacer, y de dónde saca sus datos.

Repetirle a Claude el mismo prompt de cinco párrafos cada vez que quieres lo mismo es trabajo manual disfrazado de automatización. Y el resultado cambia según el día, porque el prompt nunca sale idéntico.

Una skill es ese prompt convertido en archivo: se guarda una vez, se invoca con /nombre y responde siempre con el mismo criterio. Aquí tienes la plantilla completa, dónde va el archivo, y las tres partes que separan una skill que funciona de un prompt largo con nombre bonito.
