Contexto

El prompt que le pides a Claude antes de cerrar, para que mañana retomes en frío sin releer nada.

Trabajas tres horas con Claude, cierras el portátil, y al día siguiente abres una sesión nueva que no se acuerda de nada. Vuelves a explicar el proyecto, las decisiones, dónde os quedasteis. Cada día pagas media hora de peaje por lo mismo.

La solución no es una herramienta: es pedirle un documento de traspaso antes de cerrar, escrito para alguien que llega en frío. Aquí tienes el prompt exacto, las siete secciones que debe tener y la que de verdad importa.
